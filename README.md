# Flaura

*A lightweight macOS menu bar app that drives Razer RGB lighting without Razer Synapse: live
fire effects, a shared palette and key/mouse reactions, in sync across keyboard, mouse and mat.
The interface is in Russian.*

Flaura — лёгкая утилита для строки меню macOS, которая управляет подсветкой Razer вместо
Synapse. Главное в ней — живой огонь, но есть и спокойные эффекты. Все устройства рисуются с
одного таймера, поэтому клавиатура, мышь и коврик светятся синхронно и одной палитрой.

Название — flame + aura, и на слух почти «флора»: подсветка как что-то живое.

## Кому подойдёт

- У вас Mac и периферия Razer, а Synapse под macOS не ставится или не видит ваши устройства.
- Хочется, чтобы клавиатура, мышь и коврик светились как одно целое, а не каждый сам по себе.
- Не хочется держать тяжёлый фоновый софт: Flaura живёт в строке меню, весит около 35 МБ памяти
  и не требует драйверов и расширений ядра.

Работает из коробки с **Razer Cynosa V2**, **Basilisk V2** и **Firefly V2**: проверено на
MacBook M2 Pro с macOS 26.6. Другие устройства Razer с расширенной матрицей можно описать
JSON-файлом без пересборки (см. [«Добавить устройство»](#добавить-устройство)). Нужна macOS 14
или новее.

## Что умеет

- **Огонь**: пять видов.
  - Hearth: классический очаг.
  - Inferno: высокое пламя с белым ядром.
  - Embers: угли и искры.
  - Wisp: призрачный огонь.
  - Wildfire: пламя на ветру.
- **Эффекты**: статика, дыхание, спектр, волна, перелив, морфинг, звёзды, орбита, колесо.
- **Палитра** до четырёх цветов, общая для всех устройств. Девять пресетов и свои цвета: «+»
  добавляет случайный яркий цвет, не похожий на уже выбранные, клик по цвету открывает редактор
  (тон, насыщенность, яркость, hex, «Случайный», «Удалить»). Режим «Перетекание цветов»
  медленно прокручивает палитру по кругу поверх любого эффекта: каждый цвет перетекает в
  соседний, полоска под цветами показывает это вживую.
- **Реакции**:
  - волна расходится от нажатой клавиши, при желании через все устройства;
  - нажатая клавиша вспыхивает;
  - клик мыши даёт импульс по коврику;
  - набор текста «раздувает» огонь.
- На каждое устройство: вкл/выкл, своя яркость, свой эффект. Палитра при этом остаётся общей.
- Подсветка следует за монитором: горит, пока горит экран, в том числе на экране блокировки и
  форме входа. Гаснет, только когда монитор уснул. После выхода из Flaura устройства запоминают
  статичный цвет палитры, поэтому при следующем включении Mac клавиатура светится ещё на экране
  FileVault, до запуска macOS.

## Установка

Готовой сборки нет: приложение собирается на вашем Mac одной командой. Xcode не нужен, хватит
Command Line Tools.

1. Поставьте Command Line Tools, если их ещё нет:

   ```bash
   xcode-select --install
   ```

2. Скачайте репозиторий и запустите установку:

   ```bash
   git clone https://github.com/mrzenxxx/flaura.git
   cd flaura
   scripts/install.sh
   ```

   Скрипт собирает `build/Flaura.app`, кладёт его в `~/Applications` и запускает. В строке меню
   появится огонёк.

3. Для реакций на клавиши и клики нажмите «Разрешить…» в панели и включите Flaura в
   «Системные настройки → Конфиденциальность и безопасность → Мониторинг ввода». Самой подсветке
   разрешения не нужны.

При первой сборке скрипт создаёт в связке ключей локальный сертификат подписи «Aura Local
Signing». С ним macOS узнаёт приложение после пересборки и не сбрасывает разрешение «Мониторинг
ввода». Если macOS спросит, можно ли `codesign` пользоваться ключом, нажмите «Всегда
разрешать». Без сертификата: `scripts/install.sh --adhoc`, но тогда разрешение придётся
выдавать после каждого обновления.

Flaura добавляет себя в автозапуск и при каждом запуске проверяет, что он на месте. Отключается
в настройках Flaura или в «Системные настройки → Основные → Объекты входа».

**Обновление:** `git pull && scripts/install.sh`.

**Удаление:** выйдите из Flaura (панель → «Выйти»), затем

```bash
rm -rf ~/Applications/Flaura.app "$HOME/Library/Application Support/Aura"
```

Папка настроек называется `Aura` по старому имени приложения. Сертификат можно удалить в
«Связке ключей» (`Aura Local Signing`).

## Как это устроено

Модули в коде сохранили прежние имена (`AuraCore`, `AuraDevices`…), приложение и бинарники
называются Flaura.

```
AuraUSB      C-мост к IOUSBLib: USB control transfer на default pipe
AuraDevices  провайдеры устройств: RazerProvider (хотплаг, протокол, раскладки)
AuraCore     движок без IOKit: палитры, эффекты, слои, компоновщик, рендер-луп
AuraApp      menu bar приложение (AppKit + SwiftUI)
aura-cli     диагностика на железе (бинарник flaura-cli)
```

- **Без разрешений.** macOS требует «Мониторинг ввода», чтобы открыть HID-интерфейс мыши или
  клавиатуры. Flaura шлёт отчёты Razer как обычные USB control transfer
  (SET_REPORT/GET_REPORT, 90 байт), поэтому подсветка работает без TCC.
- **Синхронность.** Каждый кадр считается на Mac и уходит на все устройства. У каждого
  устройства своя очередь в режиме «последний кадр побеждает», так что медленное устройство не
  тормозит остальные.
- **Лёгкость.** Шлются только изменившиеся строки матрицы. На статичных эффектах таймер
  останавливается. Во сне рендер на паузе. Пока идёт анимация, App Nap отключён, иначе таймер
  душится. Огонь на трёх устройствах при 30 FPS занимает около 3–4% одного ядра, и почти всё
  это работа ядра ОС с USB. Памяти около 35 МБ.

### Добавить устройство

Любое RGB-устройство подключается через протокол `DeviceProvider` / `LightingDevice` в
`AuraCore`. Устройство описывает свои светодиоды данными (`DeviceLayout`: позиции в мм, слоты,
коды клавиш), а эффекты работают только с этими точками. Новый вендор, будь то OpenRGB SDK,
HID LampArray или Corsair, означает новый провайдер в `DeviceRegistry.standardProviders`.

Другие Razer с расширенной матрицей можно добавить без пересборки: положите JSON в
`~/Library/Application Support/Aura/devices/`:

```json
{"productID": 133, "name": "Razer Basilisk V2", "kind": "mouse", "rows": 1, "columns": 2,
 "transactionID": 31, "controlIndex": 0, "ledIDs": [1, 4], "driverMode": false, "layoutStyle": "mouse"}
```

Значения берутся из OpenRazer (`daemon/openrazer_daemon/hardware/*.py`, `driver/*.c`).

## Разработка

```bash
scripts/test.sh                     # тесты (Swift Testing из CLT)
swift build --product flaura-cli
.build/debug/flaura-cli list        # устройства
.build/debug/flaura-cli pattern     # тестовый узор для проверки раскладки
.build/debug/flaura-cli run hearth 15 --typing   # эффект без UI + замер CPU
.build/debug/flaura-cli bench       # время записи кадра
.build/debug/Flaura --snapshot /tmp/flaura-ui    # отрисовать UI в PNG
.build/debug/Flaura --selftest                   # смоук-тест AppModel: сотни случайных изменений настроек
```

Спецификация и план лежат в `docs/superpowers/`.
