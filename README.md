# Aura

Лёгкая утилита для menu bar macOS, которая заменяет Razer Synapse для подсветки. Все устройства
рисуются с одного таймера, поэтому клавиатура, мышь и коврик светятся синхронно и одной
палитрой.

Проверено на MacBook M2 Pro (macOS 26.6) с Razer Cynosa V2, Basilisk V2 и Firefly V2.

## Что умеет

- **Aura Flame**: пять видов огня.
  - Hearth: классический очаг.
  - Inferno: высокое пламя с белым ядром.
  - Embers: угли и искры.
  - Wisp: призрачный огонь.
  - Wildfire: пламя на ветру.
- **Эффекты**: статика, дыхание, спектр, волна, перелив, морфинг, звёзды, орбита, колесо.
- **Палитра** из 2–4 цветов, общая для всех устройств. Девять пресетов и свои цвета. Режим
  «Перетекание цветов» плавно гоняет цвета палитры по кругу поверх любого эффекта.
- **Реакции**:
  - волна расходится от нажатой клавиши, при желании через все устройства;
  - нажатая клавиша вспыхивает;
  - клик мыши даёт импульс по коврику;
  - набор текста «раздувает» огонь.
- На каждое устройство: вкл/выкл, своя яркость, свой эффект. Палитра при этом остаётся общей.
- Подсветка следует за монитором: горит, пока горит экран, в том числе на экране блокировки и
  форме входа. Гаснет, только когда монитор уснул. После выхода Aura устройства запоминают
  статичный цвет палитры, поэтому при следующем включении Mac клавиатура светится ещё на экране
  FileVault, до запуска macOS.

## Установка

Нужны только Command Line Tools (`xcode-select --install`), Xcode не нужен.

```bash
scripts/install.sh
```

Скрипт собирает `build/Aura.app`, ставит его в `~/Applications` и запускает. В строке меню
появится огонёк. При первом запуске Aura добавляет себя в автозапуск, это отключается в
настройках.

Реакциям на клавиши нужно разрешение «Мониторинг ввода» (кнопка «Разрешить…» в панели).
Подсветке как таковой разрешения не нужны.

## Как это устроено

```
AuraUSB      C-мост к IOUSBLib: USB control transfer на default pipe
AuraDevices  провайдеры устройств: RazerProvider (хотплаг, протокол, раскладки)
AuraCore     движок без IOKit: палитры, эффекты, слои, компоновщик, рендер-луп
AuraApp      menu bar приложение (AppKit + SwiftUI)
aura-cli     диагностика на железе
```

- **Без разрешений.** macOS требует «Мониторинг ввода», чтобы открыть HID-интерфейс мыши или
  клавиатуры. Aura шлёт отчёты Razer как обычные USB control transfer
  (SET_REPORT/GET_REPORT, 90 байт), поэтому подсветка работает без TCC.
- **Синхронность.** Каждый кадр считается на Mac и уходит на все устройства. У каждого
  устройства своя очередь в режиме «последний кадр побеждает», так что медленное устройство не
  тормозит остальные.
- **Лёгкость.** Шлются только изменившиеся строки матрицы. На статичных эффектах таймер
  останавливается. Во сне рендер на паузе. Пока идёт анимация, App Nap отключён, иначе таймер
  душится. Огонь на трёх устройствах при 30 FPS занимает около 3–4% одного ядра, и почти всё
  это работа ядра ОС с USB. Памяти около 35 МБ.

### Добавить устройство

Любое RGB-устройство подключается через протокол `DeviceProvider` / `LightingDevice` в
`AuraCore`. Устройство описывает свои светодиоды данными (`DeviceLayout`: позиции в мм, слоты,
коды клавиш), а эффекты работают только с этими точками. Новый вендор, будь то OpenRGB SDK,
HID LampArray или Corsair, означает новый провайдер в `DeviceRegistry.standardProviders`.

Другие Razer с расширенной матрицей можно добавить без пересборки: положите JSON в
`~/Library/Application Support/Aura/devices/`:

```json
{"productID": 133, "name": "Razer Basilisk V2", "kind": "mouse", "rows": 1, "columns": 2,
 "transactionID": 31, "controlIndex": 0, "ledIDs": [1, 4], "driverMode": false, "layoutStyle": "mouse"}
```

Значения берутся из OpenRazer (`daemon/openrazer_daemon/hardware/*.py`, `driver/*.c`).

## Разработка

```bash
scripts/test.sh                     # тесты (Swift Testing из CLT)
swift build --product aura-cli
.build/debug/aura-cli list          # устройства
.build/debug/aura-cli pattern       # тестовый узор для проверки раскладки
.build/debug/aura-cli run hearth 15 --typing   # эффект без UI + замер CPU
.build/debug/aura-cli bench         # время записи кадра
.build/debug/Aura --snapshot /tmp/aura-ui      # отрисовать UI в PNG
.build/debug/Aura --selftest                   # смоук-тест AppModel: сотни случайных изменений настроек
```

Спецификация и план лежат в `docs/superpowers/`.
