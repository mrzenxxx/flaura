# Aura: план реализации

> Исполняется inline в той же сессии (пользователь попросил полностью автономный процесс).
> Код пишется сразу в исходники, без дублирования в плане. В плане зафиксированы файлы,
> интерфейсы, тесты и команды проверки.

**Цель:** menu bar утилита для macOS, которая синхронно рисует эффекты (включая семейство
Aura Flame) на Razer Cynosa V2, Basilisk V2 и Firefly V2 с одной общей палитрой и расширяется на
любые RGB-устройства.

**Архитектура:** SwiftPM-пакет: `AuraUSB` (C, IOUSBLib) → `AuraDevices` (провайдеры) →
`AuraCore` (движок и эффекты, без IOKit) ← `AuraApp` (AppKit + SwiftUI) и `aura-cli`.

**Стек:** Swift 6.3 (CLT, без Xcode), macOS 14+, IOKit, AppKit, SwiftUI, Swift Testing.

**Спека:** `docs/superpowers/specs/2026-10-10-aura-design.md`

## Глобальные ограничения

- Только Command Line Tools: сборка `swift build`, тесты через `scripts/test.sh` (Swift Testing, без XCTest).
- Транспорт только USB control transfer (IOUSBLib), без IOHIDDeviceOpen, чтобы не требовать TCC.
- Палитра одна на все устройства, per-device только вкл/яркость/override эффекта/позиция.
- Лёгкость: при анимации не больше ~3% одного ядра в release, без таймера в статике, пауза во сне.
- Интерфейс на русском, код и комментарии на английском.
- В коммитах нет Co-Authored-By (глобальный CLAUDE.md пользователя).

## Факты с железа

- wIndex: Cynosa 0x01, Basilisk 0x00, Firefly 0x00. Transaction ID: 0x1F / 0x1F / 0x3F.
- Полный кадр: Cynosa ~21 мс (7 пакетов), Basilisk ~6 мс, Firefly ~6 мс.
- Ориентация подтверждена пользователем: раскладка клавиш верна, у мыши slot 0 это колесо,
  у коврика LED 0 сверху правее центра, нумерация идёт против часовой.

## Задачи

### ✅ 1. Каркас, C-мост, AuraCore (цвет, палитры, раскладки, эффекты, слои, движок)
Файлы: `Package.swift`, `Sources/AuraUSB/*`, `Sources/AuraCore/**`.
Проверка: `swift build`, затем `aura-cli run hearth 15 --typing` на железе (1.5% CPU, release).

### ✅ 2. Razer back-end и CLI
Файлы: `Sources/AuraDevices/**`, `Sources/aura-cli/main.swift`.
Проверка: `aura-cli list | bench | pattern` на железе.

### 3. Тесты
Файлы: `scripts/test.sh`, `Tests/AuraCoreTests/*.swift`, `Tests/AuraDevicesTests/*.swift`.
- Цвет: hex туда-обратно, OKLab туда-обратно (|Δ| < 0.01), `RGB.hsv` по базовым оттенкам.
- Палитра: нормализация (0 → [white], 5 → 4 цвета), LUT: `ramp(0)` чёрный, `ramp(1)` = последний
  цвет, `loop(0) == loop(1)`, `gradient` у концов; Codable в hex.
- Раскладки: `matrix` (слоты, размер), `perimeter` (точки на краю, параметр по кругу),
  SceneLayout (нормализация local/world в [0,1], диапазоны устройств), DeskArrangement (клавиатура
  слева, коврик справа, мышь на коврике, overrides).
- Эффекты: каждый `EffectKind` рендерит конечные цвета в [0, 1.01] на смешанной сцене за 120
  кадров; статика не анимирована; огонь даёт ненулевой жар внизу и меньше сверху; Stoke
  увеличивает жар в колонке; RippleLayer активен после keyDown и гаснет после lifetime.
- Движок: OutputStage (гамма 1 даёт линейный результат, 0 → 0, 1 → 255), Compositor (выключенное
  устройство чёрное, override отдаёт свою группу), RenderEngine с фейковым устройством
  (кадры приходят, статика перестаёт слать, suspended гасит).
- Razer: CRC и раскладка пакетов (известные значения из ресерча: custom frame effect crc 0x09,
  brightness `01 05 FF` crc 0xF3, firmware tid 0x1F crc 0x83), строка кадра (data size 0x47
  для 22 LED), каталог (3 модели, слоты keyboard 132 / mouse 2 / mat 19), keymap (нет дублей
  keyCode и ячеек), RazerDevice с фейковым транспортом (diff строк, effect-пакет только при
  изменениях, shutdown шлёт эффект на каждый LED id), JSON-дескриптор декодируется.
Проверка: `scripts/test.sh`, все зелёные.

### 4. Приложение: сервисы
Файлы: `Sources/AuraApp/`:
- `main.swift`: NSApplication, `.accessory`, AppDelegate.
- `AppModel.swift`: `@MainActor final class AppModel: ObservableObject`, хранит `settings`
  (`didSet`: сохранение с debounce + `engine.apply`), `devices: [DeviceInfo]`, `health`, флаги
  разрешений. Связка DeviceRegistry → `engine.setDevices`, InputMonitor → `engine.post`,
  PowerObserver → `engine.setSuspended`, activity → `ProcessInfo.beginActivity`.
- `SettingsStore.swift`: JSON в `~/Library/Application Support/Aura/settings.json`, атомарная запись.
- `InputMonitor.swift`: CGEventTap listen-only (keyDown, flagsChanged→нажатие модификатора,
  left/right/otherMouseDown), переподключение при `tapDisabledByTimeout`, `CGPreflightListenEventAccess`
  / `CGRequestListenEventAccess`; включается, только если `reactive.needsInput`.
- `PowerObserver.swift`: screensDidSleep/Wake, willSleep/didWake, distributed
  `com.apple.screenIsLocked/Unlocked`.
- `LoginItem.swift`: SMAppService.mainApp register/unregister/status.
- Выход: `engine.shutdown()` в `applicationWillTerminate`.

### 5. Приложение: UI
Файлы: `Sources/AuraApp/UI/*`:
- `StatusItemController.swift`: NSStatusItem (иконка `flame.fill`), NSPopover(.transient) с
  `PanelView`, окно настроек NSWindow + NSHostingController.
- `PanelView.swift`: шапка (Aura, вкл/выкл, яркость), плашки устройств, сетка эффектов (Aura Flame
  отдельной группой), палитра (пресеты + 2–4 ColorPicker, +/−), параметры эффекта (скорость,
  интенсивность, направление, «на все устройства», радуга), реакции (Ripple/Glow/Click/Stoke,
  длительность, цвет), футер (Настройки…, Выход).
- `SettingsView.swift`: вкладки «Устройства» (вкл, яркость, свой эффект), «Общие» (FPS, гамма,
  гасить при сне, поведение при выходе, автозапуск), «Разрешения» (статус Input Monitoring + кнопка).
Проверка: сборка, запуск .app, ручной прогон панели.

### 6. Сборка и установка
Файлы: `Resources/Info.plist`, `scripts/make-icon.swift`, `scripts/build-app.sh`,
`scripts/signing-identity.sh`, `scripts/install.sh`, `README.md`.
- Info.plist: `CFBundleIdentifier=dev.archigene.aura`, LSUIElement, версия.
- Иконка рисуется скриптом в .icns (iconutil).
- Подпись: если есть identity «Aura Local Signing», подписываем ей (стабильный TCC), иначе ad-hoc.
- install: `~/Applications/Aura.app`, запуск через `open`.
Проверка: `scripts/install.sh`, приложение в menu bar, эффекты на железе.

### 7. Проверка на железе и тюнинг
Каждый эффект по очереди через приложение, замер CPU (`ps -o %cpu`) и памяти (RSS), проверка
сна и разблокировки, переподключения USB, выхода (аппаратный static).
