# Aura — дизайн

Дата: 2026-10-10. Статус: утверждено (автономный режим по просьбе пользователя).

## Задача

На macOS нет Razer Synapse. Подсветка Razer Cynosa V2 (клавиатура), Basilisk V2 (мышь) и
Firefly V2 (коврик) крутит аппаратные эффекты, у каждого устройства свой таймер, поэтому через
USB-хаб они светятся вразнобой. Нужна лёгкая фоновая утилита для menu bar, которая:

- рисует красивые эффекты в духе Chroma Studio: огонь (несколько вариантов, семейство
  **Aura Flame**), волны, переливы, звёздное небо, реакцию на клавиши и клики;
- держит **одну палитру на все три устройства одновременно** и рисует их синхронно;
- позволяет настраивать цвета: 2–4 цвета палитры и режим плавного перетекания между ними;
- с самого начала устроена так, чтобы позже подключать любые RGB-устройства, не только Razer.

Железо пользователя: MacBook M2 Pro, macOS 26.6.2, Command Line Tools со Swift 6.3, без Xcode.

## Что проверено на железе (до проектирования)

- Все три устройства на шине (VID 0x1532): Cynosa V2 0x025E, Basilisk V2 0x0085, Firefly V2 0x0C04.
- Через HID (IOHIDDeviceOpen) macOS возвращает `kIOReturnNotPermitted`, потому что нужен TCC
  «Мониторинг ввода». **Не используем.**
- Через USB control transfer (IOUSBLib `DeviceRequest` на default pipe, SET_REPORT 0x21/0x09,
  wValue 0x0300, wIndex 0, GET_REPORT 0xA1/0x01) все три отвечают без всяких разрешений.
  Transaction ID 0x1F, статус 0x02 (success). Прошивки: Firefly 1.0, Cynosa 1.0, Basilisk 1.4.
- Custom frame расширенной матрицы (класс 0x0F, команда 0x03 на строку + 0x0F/0x02 с эффектом
  0x08) все три принимают со статусом success.
- Swift Testing работает с CLT, если передать `-F/Library/Developer/CommandLineTools/Library/Developer/Frameworks`.

## Подход

Рассматривали три варианта:

1. **Софтверный рендер на хосте + прямые кадры (выбран).** Каждый кадр считаем на Mac и
   отправляем на все устройства. Синхронизация гарантирована, так как часы одни, и любые эффекты
   и реакции возможны. Цена: постоянный USB-трафик (~10 control transfer на кадр).
2. Аппаратные эффекты устройств + периодическая пересинхронизация. Почти ноль CPU, но нет огня,
   ripple через все устройства и общей палитры с перетеканием. Отклонён, проблему не решает.
3. Обёртка над OpenRGB. Тяжело, нужен внешний сервер. Оставлен как возможный будущий провайдер.

Лёгкость при варианте 1 обеспечиваем так:
- шлём только изменившиеся строки, а статичные эффекты почти не грузят шину;
- рендер-луп на `DispatchSourceTimer` с leeway, 30 FPS по умолчанию (настраивается 15–60);
- если эффект статичный и реактивных анимаций нет, таймер останавливается полностью;
- подсветка следует за монитором: горит, пока горит любой дисплей (рабочий стол, экран
  блокировки, форма входа), гаснет при сне дисплеев и сне системы;
- UI (SwiftUI MenuBarExtra) не подписан на кадры и не живёт, когда панель закрыта.

## Архитектура

SwiftPM-пакет `Aura`, пять таргетов:

```
AuraUSB (C)      тонкий мост к IOUSBLib: open по registryEntryID, control transfer с таймаутом
AuraCore         без IOKit: цвет, палитры, раскладки LED, эффекты, слои, компоновщик, движок
AuraDevices      провайдеры устройств: протокол DeviceProvider + RazerProvider (USB-хотплаг,
                 каталог устройств, протокол пакетов, раскладки, карта клавиш)
AuraApp          menu bar приложение: UI, настройки, InputMonitor, питание, автозапуск
aura-cli         диагностика: list, test-pattern, run <effect> без UI
```

### Модель устройств (расширяемость)

```swift
protocol LightingDevice: AnyObject {
    var id: DeviceID { get }              // стабильный: vendor:product:location
    var info: DeviceInfo { get }          // имя, kind (keyboard/mouse/mousepad/strip/other)
    var layout: DeviceLayout { get }      // LED-точки с локальными координатами
    func write(frame: FrameSlice) throws  // цвета в порядке layout.leds
    func shutdown()                       // погасить или вернуть аппаратный эффект
}
protocol DeviceProvider: AnyObject {      // источник устройств одного семейства
    var name: String { get }
    func start(onChange: @escaping ([LightingDevice]) -> Void)
    func stop()
}
```

`DeviceLayout` описывает геометрию данными: у каждого LED есть индекс в матрице устройства,
физическая позиция в миллиметрах, нормализованная локальная позиция (u, v) ∈ [0,1]², опциональный
параметр периметра (0…1 по краю, для коврика) и опционально keyCode. Эффекты работают только с
этими точками и ничего не знают о Razer. Новый вендор означает новый `DeviceProvider`
(OpenRGB SDK, HID LampArray, Corsair и т.д.), а движок и эффекты остаются без изменений.

Каталог Razer задан данными (`RazerDeviceDescriptor`: PID, имя, kind, rows×cols, transaction ID,
семейство команд, построитель раскладки). Дополнительные Razer-устройства можно добавить
JSON-файлом в `~/Library/Application Support/Aura/devices/`.

### Сцена и координаты

Устройства стоят на «виртуальном столе»: клавиатура слева, коврик справа, мышь на коврике.
Позиции по умолчанию заданы, их можно поправить в настройках. У каждой LED-точки три системы координат:
- `local (u,v)`: внутри своего устройства, чтобы огонь поднимался от нижнего края каждого устройства;
- `world (x,y)`: на всём столе, чтобы волна и ripple переходили с клавиатуры на коврик;
- `perimeter p`: положение по краю (для коврика), под бегущие огни по контуру.

Эффект сам выбирает пространство. Опция «Растянуть на все устройства» переключает local/world.

### Палитра

Одна глобальная `Palette` на сцену, 2–4 цвета (пресеты: Пламя, Лёд, Токсик, Закат, Океан,
Синтвейв, Аврора, Кровь). Интерполяция в OKLab, чтобы перетекание шло без грязных серых
переходов. Из палитры строятся LUT на 256 значений: `loop` (замкнутый цикл для перетекания) и
`ramp` (чёрный → цвета, тепловая карта огня). Все эффекты берут цвета только из палитры, кроме
Spectrum и Rainbow Wave, у которых радуга по определению.

### Эффекты (базовый слой)

| Эффект | Описание |
|---|---|
| Static | цвета палитры градиентом по сцене (или один цвет) |
| Breathing | дыхание с переходом к следующему цвету палитры на каждом вдохе |
| Spectrum | весь спектр синхронно на всех устройствах |
| Wave | бегущая волна палитры или радуги, направление ←→↑↓, через все устройства |
| Flow | цвета палитры плавно перетекают друг в друга и медленно дрейфуют (запрошено) |
| Morph | вся подсветка целиком плавно меняет цвет по кругу палитры |
| Starlight | звёзды вспыхивают и гаснут в цветах палитры на тёмном фоне |
| Orbit | «комета» бежит по периметру (коврик, контур клавиатуры) |
| **Aura Flame · Hearth** | классический огонь (heat diffusion, Fire2012) |
| **Aura Flame · Inferno** | высокие быстрые языки, белое ядро (Doom-fire, сильная искра) |
| **Aura Flame · Embers** | тлеющие угли: низкое пламя, пульсирующий жар, искры летят вверх |
| **Aura Flame · Wisp** | призрачный мягкий огонь на шуме (domain-warp), по умолчанию синяя палитра |
| **Aura Flame · Wildfire** | пламя «гуляет» по ширине: порывы ветра сносят языки в стороны |

Параметры, общие для эффектов: скорость, яркость, направление (где применимо), «растянуть на все
устройства». Для огня ещё высота пламени и интенсивность. Цвета огня берутся из ramp палитры,
поэтому синий, зелёный или фиолетовый огонь делается сменой палитры.

### Реактивные слои (поверх базового)

| Слой | Триггер | Поведение |
|---|---|---|
| Ripple | клавиша | кольцо расходится от нажатой клавиши; при «растянуть» переходит на коврик и мышь |
| Key Glow | клавиша | клавиша вспыхивает и гаснет (коротко/средне/долго) |
| Click Pulse | клик мыши | мышь вспыхивает, от её позиции по коврику идёт кольцо |
| Stoke | клавиша | подбрасывает жар в огонь в колонке клавиши (только для Aura Flame) |

Цвет слоя берётся из палитры: самый яркий цвет, следующий по кругу или «контраст». Слои
смешиваются через screen/additive и затухают сами. Пока активных анимаций нет, слой ничего не
стоит.

Для реакций нужен TCC «Мониторинг ввода» (CGEventTap listen-only). Разрешение запрашивается
только при включении реактивного слоя, а без него остальное работает. Клики мыши ловим тем же
event tap.

### Пер-девайсные настройки

У каждого устройства есть: вкл/выкл, яркость-множитель (коврик обычно ярче) и необязательный
override эффекта («следовать сцене» по умолчанию). Палитра всегда общая: это главное требование.

### Движок и поток данных

```
Timer(30 FPS) → RenderEngine.tick(t, dt)
  → Compositor: base effect(s) пишут в [RGB] для всех точек сцены
  → overlay layers (ripple/glow/pulse) добавляют свечение
  → OutputStage: brightness × per-device gain → gamma → UInt8
  → для каждого устройства: diff с прошлым кадром → write(frame:) на своей serial-очереди
```

У каждого устройства своя очередь, поэтому медленное устройство не тормозит остальные. Если
устройство ещё не закончило прошлый кадр, новый кадр перезаписывает отложенный (latest-wins),
и очередь не растёт.

Настройки (`AuraSettings`, Codable) хранятся в `~/Library/Application Support/Aura/settings.json`.
UI меняет их на main, движок получает снапшот через свою очередь.

### Ошибки и хотплаг

- Подключение и отключение USB ловим через `IOServiceAddMatchingNotification`. Устройство
  добавляется или убирается из сцены на лету, остальные продолжают работать.
- Ошибка записи (устройство пропало, таймаут) переводит устройство в состояние «degraded»
  с экспоненциальным backoff. После трёх неудач подряд устройство переоткрывается.
- Таймаут control transfer 100 мс, поэтому зависшее устройство не блокирует рендер.
- При выходе устройства получают аппаратный static или spectrum (настраивается), чтобы не
  застыть на последнем кадре.

### UI

Menu bar, иконка `flame` (SF Symbol). Панель MenuBarExtra(.window):
- заголовок «Aura», общий переключатель, яркость;
- плашки устройств со статусом подключения;
- сетка эффектов (Aura Flame сгруппированы);
- палитра: 2–4 color well, пресеты, режим «перетекание»;
- скорость и параметры эффекта, реактивные слои;
- «Настройки…» (отдельное окно: устройства, FPS, автозапуск, разрешения, раскладка стола), «Выход».

### Сборка и поставка

- `scripts/test.sh`: `swift test` с путями к Testing.framework из CLT.
- `scripts/build-app.sh`: `swift build -c release`, сборка `build/Aura.app` (Info.plist с
  LSUIElement, иконка), codesign. Если в связке есть стабильная локальная подпись, используем её,
  чтобы TCC-разрешение не слетало при пересборке; иначе ad-hoc.
- `scripts/install.sh`: копирует в `~/Applications/Aura.app`, регистрирует автозапуск
  (SMAppService), запускает.

### Тестирование

- AuraCore: цвет и OKLab, палитры и LUT, детерминизм эффектов (seeded RNG), компоновщик и
  смешивание, diff, пауза движка.
- AuraDevices: сборка пакетов Razer (CRC, размеры, разбиение строк), каталог, раскладки
  (число LED, нормализация), карта клавиш, фейковый транспорт.
- Железо: `aura-cli test-pattern` для визуальной проверки порядка LED, `aura-cli run` для
  проверки FPS и нагрузки CPU.

## Вне рамок (пока)

Audio visualizer, синхронизация с экраном (ambient), макросы и DPI мыши, провайдеры для других
вендоров. Для них есть точки расширения, но реализации сейчас нет.
